# ATP009 — Kubernetes and Cloud Native Security Associate (KCSA)

Preparation scaffold: one stage per exam domain, connected through `path.yaml`
to a training series repository. New material is planned, and the course
registration in `astrona-content` stays **draft**.

This exam is part of the current Golden Kubestronaut requirements.

| Stage | Domain | Weight | Series |
| --- | --- | --- | --- |
| STG001 | Overview of Cloud Native Security | 14% | [ATS041](https://github.com/astrona-io/ATS041) |
| STG002 | Kubernetes Cluster Component Security | 22% | [ATS042](https://github.com/astrona-io/ATS042) |
| STG003 | Kubernetes Security Fundamentals | 22% | [ATS043](https://github.com/astrona-io/ATS043) |
| STG004 | Kubernetes Threat Model | 16% | [ATS044](https://github.com/astrona-io/ATS044) |
| STG005 | Platform Security | 16% | [ATS045](https://github.com/astrona-io/ATS045) |
| STG006 | Compliance and Security Frameworks | 10% | [ATS046](https://github.com/astrona-io/ATS046) |
